# Трекер привычек для MAX

Бот для мессенджера MAX, который помогает отслеживать привычки, отправляет напоминания и ведёт статистику.  
Проект написан на Python, использует SQLite и запускается либо напрямую, либо в Docker-контейнере.

## Стек технологий

- **Python 3.10**
- **maxgram** — SDK для платформы MAX (обработка сообщений и callback-кнопок)
- **requests** — отправка HTTP-запросов в API MAX из планировщика напоминаний
- **SQLite (sqlite3)** — встроенная база данных для хранения привычек, прогресса и напоминаний

---

## Подготовка

1. Склонируйте/скачайте проект или просто положите все файлы (`main.py`, `bot.py`, `scheduler.py`, `storage.py`, `config.py`, `requirements.txt`, `Dockerfile`, `README.md`) в одну папку.
2. Откройте файл **`config.py`** и:
   - вставьте **токен бота MAX** в переменную `BOT_TOKEN`;
   - при желании поменяйте путь к базе данных `DB_PATH` (по умолчанию `habits.db` в корне проекта).

> Токен будет "зашит" в Docker-образ, поэтому для продакшена лучше выносить его в переменные окружения, но для учебного проекта можно оставить так.
