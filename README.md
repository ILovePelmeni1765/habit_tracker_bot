# Трекер привычек для MAX

Этот репозиторий содержит артефакты для запуска бота **«Трекер привычек»** для мессенджера MAX:

- готовый Docker-образ в файле `max-habits-bot.tar`;
- файл зависимостей `requirements.txt`;
- файл `README.md` с подробной инструкцией по запуску.

Ниже описано, как запустить решение:

1. **локально (из исходного кода)**;
2. **через Docker-образ** (из `max-habits-bot.tar`);
3. как **собрать образ контейнера** и **запустить контейнер**, с примерами команд.

---

## 1. Структура репозитория

В данном репозитории находятся:

- `requirements.txt` — список Python-зависимостей проекта;
- `max-habits-bot.tar` — готовый Docker-образ бота в формате TAR;
- `README.md` — текущий файл с инструкцией по запуску.

> Исходный код проекта (файлы `main.py`, `bot.py`, `scheduler.py`, `storage.py`, `config.py` и др.) может поставляться отдельно (например, в виде архива или в другом репозитории). Для локального запуска без Docker он необходим.

---

## 2. Системные требования

### 2.1. Для локального запуска (без Docker)

- Python **3.10+**;
- `pip` (менеджер пакетов Python).

### 2.2. Для запуска в Docker

- установленный **Docker** (Docker Desktop для Windows/macOS или Docker Engine для Linux).

Проверить, что Docker установлен, можно командой:

```bash
docker --version
```
## 3. Локальный запуск (из исходного кода)

Этот раздел применим, если у вас есть исходный код проекта (например, в отдельном архиве).
В текущем репозитории исходные файлы бота не размещены.

### 3.1. Подготовка окружения

Распакуйте или склонируйте проект с исходным кодом бота в отдельную папку.
Убедитесь, что в корне проекта лежат:

файлы исходного кода (main.py, bot.py, scheduler.py, storage.py, config.py и др.);

файл requirements.txt (можно взять из текущего репозитория).

### Установка зависимостей

Рекомендуется использовать виртуальное окружение.

Linux / macOS
# перейти в папку проекта с исходниками
```cd /путь/к/проекту```

# создать виртуальное окружение (опционально)

```
python3 -m venv venv
source venv/bin/activate
```
# установить зависимости
```pip install -r requirements.txt```

Windows (PowerShell)
# перейти в папку проекта с исходниками
cd C:\путь\к\проекту

# создать виртуальное окружение (опционально)
python -m venv venv
venv\Scripts\Activate.ps1

# установить зависимости
pip install -r requirements.txt

### Запуск бота

Linux / macOS
```python3 main.py```

Windows
```python main.py```

При первом запуске в каталоге проекта будет создана база данных (например, habits.db).
Остановить бота можно сочетанием клавиш Ctrl + C.

## 4. Запуск решения через готовый Docker-образ (max-habits-bot.tar)

Основной способ воспроизведения решения из данного репозитория — запуск контейнера на основе подготовленного Docker-образа max-habits-bot.tar.

### 4.1. Загрузка Docker-образа из файла

Скачайте файл max-habits-bot.tar из репозитория (корень проекта).

В терминале перейдите в каталог, где находится файл max-habits-bot.tar.

Пример (Windows, PowerShell):

```cd C:\Users\Пользователь\Downloads```

Пример (Linux / macOS):

```cd ~/Downloads```

Загрузите образ в Docker:

```docker load -i max-habits-bot.tar```

После выполнения команды образ станет доступен во внутреннем хранилище Docker.
Проверить можно так:

```docker images```

Ожидается, что среди образов будет:

REPOSITORY        TAG       IMAGE ID       ...

max-habits-bot    latest    ...

### 4.2. Запуск контейнера из загруженного образа

После загрузки образа выполните команду запуска контейнера.

Универсальная команда (Linux / macOS / Windows):

```docker run -d --name max-habits-bot max-habits-bot```

Где:

-d — запуск в фоновом режиме (detached);

--name max-habits-bot — имя контейнера;

max-habits-bot — имя образа, загруженного из max-habits-bot.tar.

Пример запуска через командную строку (Windows, PowerShell):

```PS C:\Users\Пользователь> docker run -d --name max-habits-bot max-habits-bot```

После запуска внутри контейнера стартует бот и все необходимые фоновые процессы (например, планировщик напоминаний).
Проверить работу можно по логам.

### 4.3. Работа с логами и управление контейнером

Просмотр логов контейнера (разовый вывод):

```docker logs max-habits-bot```

Просмотр логов в режиме «следить» (stream):

```docker logs -f max-habits-bot```

Остановка контейнера:

```docker stop max-habits-bot```

Повторный запуск остановленного контейнера:

```docker start max-habits-bot```

Удаление контейнера (при необходимости):

```docker rm -f max-habits-bot```
